## Gotchas

- **Prompts exist twice**: nudge (`GeminiClient.kt` / `nudge.ts`) and chat (`GeminiChat.kt` /
  `chat.ts`), plus `Persona.promptRole` / `PERSONA_ROLES`. Change both sides together.
- **Settings JSON omits values equal to their default**, so changing a default in `UserSettings`
  silently changes it for existing users (see `8124868`).
- **Old `workStartMinute`/`workEndMinute` keys are ignored** on `feature/chat-input`; existing installs
  fall back to wake 07:00 / bed 23:00.
- **Testing the overlay bubble**: the in-app "💬 Thử" button now posts to the chat only. Press Home,
  then `adb shell am broadcast -a com.hydrachat.app.action.REMIND -n com.hydrachat.app/.reminder.ReminderReceiver`
  (it does nothing if today's target is already reached or it is outside the reminder window).
- **Testing the system bubble**: revoke the overlay permission and enable bubbles with
  `adb shell cmd notification set_bubbles com.hydrachat.app 1`.
- **`adb input text` cannot type Vietnamese**; use ASCII when scripting chat tests.
- The repository is **public**: never commit keys or `google-services.json`.
