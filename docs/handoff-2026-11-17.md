## Gotchas for whoever picks this up

- **SDK path**: the build needs `local.properties` with `sdk.dir=<your Android SDK>` (git-ignored) or `ANDROID_HOME`.
  AGP downloads Platform 37 and Build-Tools 36 on the first build if the SDK license is accepted.
- **AGP 9 built-in Kotlin**: do not re-add `org.jetbrains.kotlin.android` or `kotlinOptions`; Kotlin
  and KSP versions come from the root `build.gradle.kts` and override AGP's defaults.
- **compileSdk 37 vs targetSdk 36 is intentional**: AndroidX core 1.19 needs compileSdk 37, while
  Play only requires targetSdk 36.
- **IDE after the AGP 9 upgrade**: the VS Code Kotlin plugin may show "Unresolved reference: android"
  everywhere until the Gradle project is re-imported. Trust the Gradle build.
- **`run-emulator.sh` boots an AVD named `hydra_test`**. If yours has another name, start it first —
  the script skips booting when an emulator is already running.
- **Persona prompts exist twice**: `Persona.promptRole` (app) and `PERSONA_ROLES` in
  `backend/functions/src/nudge.ts`. Change both together.
- **Testing the system bubble**: revoke the overlay permission, enable bubbles with
  `adb shell cmd notification set_bubbles com.hydrachat.app 1`, then tap "🫧 Thử" on the Home tab.
